# 今天吃什么？（luckydraw）

一个用 Flask 写的「今天吃什么」抽奖小工具：选好用餐时段（早 / 中 / 晚）和人数（单人 / 双人），从对应奖池里随机抽出一套搭配，并展示每道菜的分步做法。

## 功能

- 六个奖池：早餐 / 午餐 / 晚餐 × 单人 / 双人，共近百套搭配
- 等概率随机抽取（`random.SystemRandom`，不可预测）
- 结果包含套餐结构、预计耗时、备注，以及每道菜的用料、调料、做法、关键点
- 菜谱全部来自纯文本清单，改文本即可增删搭配，无需改代码
- 启动时校验数据：奖池为空、引用了不存在的做法编号都会直接报错

## 快速开始

```bash
pip install -r requirements.txt
python luckydraw.py
```

打开 http://127.0.0.1:5000

## 运行测试

```bash
python test_luckydraw.py
```

覆盖清单解析、抽奖分布、接口参数校验与六种组合的返回内容。

## 接口

`POST /api/draw`

```json
{ "period": "中", "mode": "单人" }
```

- `period`：`早` / `中` / `晚`
- `mode`：`单人` / `双人`

成功返回 `{ "ok": true, "result": { ... } }`；参数缺失或非法返回 400 及错误信息。

## 数据格式

`家常饭食清单.txt` 里的搭配形如：

```
B1-01｜小米南瓜粥 ＋ 茶叶蛋 ＋ 拍黄瓜
  做法：Z01 ＋ Z23 ＋ X01 ｜ 耗时 25 分钟（茶叶蛋前一晚煮）
  结构：粥 ＋ 蛋 ＋ 小菜，最省事的一套
```

做法库条目形如：

```
【Z01】小米南瓜粥
  份量：1 人份
  用料：小米 50g、南瓜 150g、水 700ml
  做法：
1. ...
```

`B1` / `B2` / `L1` / `L2` / `D1` / `D2` 分别对应早中晚的单人与双人奖池；方括号里的编号是大写字母加两位数字，被搭配行引用。
